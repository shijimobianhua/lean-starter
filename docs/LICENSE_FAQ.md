# 许可常见问题

- **个人修改和部署可以吗？** 可以，在遵守LICENSE的个人非商业范围内。
- **自己支付域名或服务器费用可以吗？** 为自己的个人使用支付托管成本，本身不等于经营性变现；服务用途仍应符合个人非商业范围。
- **能出售安装包、收会员、接广告或收费代部署吗？** 当前许可不允许，须另行书面商业授权。
- **改名改配色后可以商用吗？** 包含原项目受许可内容时仍受约束，改名不会解除限制。
- **能用自己的名称和标识吗？** 可以，保留来源和许可入口，说明是非官方版本，不冒充官方。
- **可以分享自己的非商业修改吗？** 可以，保留LICENSE和NOTICE，标明修改，不为原内容另授商业权利。
- **GitHub公开是否意味着任意用途？** 不是。平台允许的查看/Fork与商业再利用不是同一项许可。
- **第三方组件也被禁止商用了吗？** 本项目许可不替换第三方组件自己的许可；独立使用第三方组件按其原条件处理。
- **源码能操作原站吗？** 本仓库没有原站发布权限。个人部署使用自己的新项目，不能更新或访问原站数据。
- **是否提供法律保证或完全防盗？** 不提供。许可约束、来源记录和账号隔离各有作用，不能技术上阻止所有未经授权的复制行为。

以LICENSE中文正文为准。来源和商业授权联系入口见NOTICE。
