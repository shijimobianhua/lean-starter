# 交给 Codex 或其他 AI 编程工具

这个项目可以用 Codex、Cursor、Claude Code 或其他能读写本地代码的工具修改。运行应用本身不需要任何 AI API key。工具是否能部署取决于你自己的账号、权限及环境，仓库不会自动赋予发布权限。

## 第一次打开项目

1. 用模板、Fork 或下载ZIP取得自己的副本。
2. 在自己的代码目录运行 npm ci。
3. 把当前目录加入 AI 开发工具，不要指向薄肌 LEAN 正式项目或别人的仓库。
4. 使用下面的任务说明；先跑通现有版本，再逐步改变。

## 完整任务提示词

```text
请先阅读 README.md、AGENTS.md、LICENSE、NOTICE、docs/DEPLOY.md。
这是我自己的个人非商业副本。先检查 Git 状态、Node版本和现有结构，运行检查、测试和构建。
然后实现我的要求：[写清页面、交互、配色或功能]。

必须保留现有本机记录、照片、备份恢复、单位和学位计算。改品牌不随意更改数据库键或清除用户数据。
保留原有来源、许可与第三方声明；说明我新增或修改的部分，不把原项目冒认为完全独立原创。
保持默认/薄肌与浅/深模式可用，检查320px、软键盘、焦点与减少动态。
分享二维码和复制链接指向我的独立站点。

先在我自己的 feature/ 或 codex/ 分支开发并说明变更。
如我明确要求发布，只部署到我自己的托管账号与新项目。没有权限时告诉我需要的最小操作。
不得连接、更新或部署薄肌 LEAN 正式站，不得索取原作者的部署凭据。
完成后给出测试结果、截图、数据兼容说明及我自己的真实发布地址；没有发布成功不要声称上线。
```

## 常用改动示例

- “保留全部功能，把薄肌风格的橙色改成我选的低饱和蓝，并独立适配深浅模式，别改数据口径。”
- “为我的个人副本改浏览器/PWA名称和图标，保留来源入口，二维码指向我自己的域名。”
- “改善训练搜索交互，保留草稿、中文输入法和历史训练记录，新增针对真实故障的测试。”
- “把我自己的仓库部署到我的 Cloudflare Pages，新建项目，不复用上游托管身份。”

## 如何提出有效需求

先说目的，再指出具体页面和操作。截图中圈出问题，说明手机尺寸、明暗模式、如何复现。一次先完成一组相互关联的改动，避免同时改数据库、品牌、部署和统计口径导致难以定位。

排错时可分享错误信息和脱敏截图，不要把个人照片、完整健康备份、账号令牌或浏览器凭据交给公开Issue。先导出备份，再做需要数据迁移的更改。
